# Options Portal

FastAPI + React options portal with an expiry-day short-strangle automation
script (NIFTY / SENSEX), Shoonya order execution, Upstox market data, and
optional Telegram alerts.

## Setup & usage

See **[INSTALL.md](INSTALL.md)** for installation, running the web server,
configuring and scheduling the strangle automation, and Telegram setup.
